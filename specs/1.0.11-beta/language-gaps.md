# Language gaps — 1.0.11-beta

Carried whole from 1.0.10-beta (its closed rows were deleted there, per the file's own rule), re-owned
to this milestone's fronts, with the rows the milestone's opening audit found without one added at
the end of each table.

The compiler is frozen for every **library** front. A library front is built from plain botopink
plus `@Decl`, comptime, `@emit` and `#[@External.<Target>]`; one that needs a compiler change does
not get one — it writes the nearest form that parses today, marks the line `// LANGUAGE GAP:`, and
records the gap here. The compiler is **not** frozen for [`01-compiler`](./01-compiler/README.md),
whose fronts keep their 1.0.10 sub-front numbers: an owner written `00 · 13` in 1.0.10 is
`01-compiler/13-…` here, and `26-cli-tooling` is new. A gap owned by a compiler front is **still
worked around** by the library front that hits it — the compiler runs beside the libraries, not
ahead of them.

**The exit gate of the milestone** (`fronts.md`): every `// LANGUAGE GAP:` marker in a library's
code or in a front's `examples/` names a row here; a marker with no row is red. The gate's grep
excludes `specs/1.0.10-beta/**`, which is frozen.

A row gated on a maintainer question names it (`lg-a`, `lg-b`, `lg2-a…w`, `ck-host`; all in
[`decisions-pending.md`](./decisions-pending.md) § Open). Until the question is answered the row
opens no front: the recommendation everywhere is the most restrictive reading — the feature stays
out and the nearest form is the design.

`hook-integrity` workflow, check 5): a **marker** is the literal `// LANGUAGE GAP` in a tracked
`.bp` file of any repository under `repository/`, or of this repository outside the closed
milestones' spec trees. One row per file that holds a marker — its path from the meta root, how
many markers it holds, and the gap row(s) of the tables below that those markers name, each spelled
as the table spells its bold title. The script fails when a file with a marker has no row here, when
a count differs from the file's, when a named gap row is gone from the tables (the gap closed: the
marker goes first), and when a row here names a file with no marker. No flag exempts a file.
