# Absorbed — the raw originals of 1.0.6-beta … 1.0.9-beta

The four directories were deleted on 2026-09-20 (decision 68) after every file was carried into
this milestone. What is here is the **verbatim** copy of the documents whose content was merged
rather than copied by name, so that the lossless-merge claim of [`../unification.md`](../unification.md)
can be re-checked against the source forever:

| Directory | Holds |
|---|---|
| `1.0.6-beta/` | `overview.md`, `fronts.md`, the 20 front READMEs (rakun drafts, merged into `../03-rakun/`) |
| `1.0.7-beta/` | `overview.md`, `fronts.md`, `examples-bp.md`, the 22 front READMEs (onze13 / jhonstart / rakun server half / emilia attributes / std, merged into `../06-onze/`, `../04-jhonstart/`, `../03-rakun/`, `../05-emilia/`, `../01-std/`) |
| `1.0.8-beta/` | `overview.md`, `fronts.md`, `tailwind-mapping.md`, the 15 front READMEs (emilia drafts, merged into `../05-emilia/`) |
| `1.0.9-beta/` | `overview.md`, `fronts.md`, `contracts.md`, `deferred.md`, `language-gaps.md`, `tracks/README.md` — the documents this milestone's top-level files were carried from |

The 1.0.9 front directories themselves are not here: they were copied by name, unchanged above
their `## Carried from …` sections, into `../01-std/`, `../02-packaging/`, `../03-rakun/`,
`../04-jhonstart/`, `../05-emilia/` and `../06-onze/`. The `examples/*.bp` of 1.0.6 and 1.0.8 were
copied into the counterpart fronts' `examples/` (a name clash keeps both, the older with a
`-1.0.8` suffix).

Nothing here is a spec: read the front under its track, not the draft. Links inside these files
point at paths that no longer exist and are left as written.
